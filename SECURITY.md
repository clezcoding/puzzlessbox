# Security Policy

## Supported versions

Security fixes target the `main` branch of this repository.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email: **clezcoding** via GitHub security advisories:

1. Open https://github.com/clezcoding/puzzlessbox/security/advisories/new
2. Or contact the repo owner through GitHub privately

Include: affected component, reproduction steps, impact, and any suggested fix.

We aim to acknowledge reports within 7 days.

## Automated scanning

- **CodeQL** — GitHub default setup (`actions`, `javascript-typescript`, `python`)
- **Dependabot** / **Renovate** — dependency and Actions updates
- **Secret scanning** + push protection — enabled on this public repository
