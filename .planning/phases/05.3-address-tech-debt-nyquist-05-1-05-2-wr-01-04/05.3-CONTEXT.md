- **D-01:** Treat Nyquist closure as first-class deliverables of this phase for **both** 05.1 and 05.2: update each phase's `VALIDATION.md` per-task map to match tests that already exist, run the mapped commands green, then set frontmatter `status: validated` and `nyquist_compliant: true`. — **Reversibility:** reversible — frontmatter/docs only once tests already pass
- **D-02:** Do **not** invent new product features or Wave-0 stub files for coverage theater. Prefer aligning maps to reality (`api/tests/integration/test_bootstrap.py`, MCP auth tests, webapp `poweredByHeader` test, 05.2 scrape/calendar/OAuth suites). If a map row still points at a missing automated check for an already-shipped behavior, add the **smallest** missing test — not a redesign. — **Reversibility:** reversible
- **D-03:** Manual-only rows (live HSTS / banner strip / apex negative) stay manual; do not block `nyquist_compliant` on redoing Coolify Traefik work already verified live in the audit. Document last-verified date/command in VALIDATION or UAT. — **Reversibility:** reversible

### WR-01..04 bootstrap / HMAC polish
- **D-04:** Fix **all four** warnings (WR-01..04) in code with regression tests — not docs-only. — **Reversibility:** reversible
- **D-05 (WR-01):** Resolve/validate bootstrap token **before** any `service_principals` insert. On prod refuse (empty `MCP_BOOTSTRAP_TOKEN`), return with **zero** DB writes — no partial SP row. — **Reversibility:** reversible
- **D-06 (WR-02):** Prefer `0600` file under a known local path (e.g. `.local/mcp-bootstrap-token`, gitignored) plus a one-line stdout hint that names the path. Gate any plaintext token on stdout with `sys.stdout.isatty()` so Coolify/Docker log streams never collect the token. Keep D-03: never `logger.*` plaintext. — **Reversibility:** reversible
- **D-07 (WR-03):** At every `SERVICE_BEARER` / `hmac.compare_digest` call site used for auth (`api/app/auth/jwt.py`, `api/app/routers/internal.py` at minimum), reject empty or length-mismatched bearer with **401** before calling `compare_digest` (no TypeError → 500). Calendar webhook HMAC is out of this WR unless it shares the same bug pattern and is cheap to align. — **Reversibility:** reversible
- **D-08 (WR-04):** When `mcp_clients` is empty and `"user"` count **> 1**: require explicit `SERVICE_OWNER_ID` (env) or refuse bootstrap with a clear error log — do **not** silently bind earliest `createdAt ASC`. When count == 1, keep first-user auto-bind. — **Reversibility:** reversible — ops edge path only
