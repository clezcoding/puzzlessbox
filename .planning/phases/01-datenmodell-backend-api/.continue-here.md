**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Firecrawl harness all-in-one | Harness spawns API+workers in one container → OOM restart | blocking | Keep split-worker compose; never revert to harness-only |
| Wrong health endpoint | `/health` returns 404 on Firecrawl self-host | blocking | Use `/v0/health/liveness` in code and compose healthcheck |
| UUID DNS for compose sub-apps | `http://{sub-app-uuid}:3002` from API often fails | blocking | API on scraper Docker network; use container/service names |
| Camoufox alias without redeploy sync | Alias lost or stale after Camoufox restart | advisory | Add `camoufox` service to `docker-compose.scraper.yml` or automate URL update on deploy |
