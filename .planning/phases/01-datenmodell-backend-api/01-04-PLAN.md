| Google→/auth/google/callback | OAuth code exchange; verify state CSRF token |

| FastAPI→Postgres calendar_tokens | Encrypted at rest (D-17) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-oauth-csrf | Tampering | OAuth callback state | high | mitigate | OAuth Flow state param verified on callback; reject mismatch |
| T-01-token-exposure | Information Disclosure | plain-text refresh tokens in DB | high | mitigate | AES-256-GCM encrypt at rest; ENCRYPTION_KEY from Coolify secret (D-17) |

| T-01-SC | Tampering | pip installs (google-api-python-client, google-auth-oauthlib) | high | mitigate | Both [OK] per RESEARCH Package Legitimacy Audit; pin versions in requirements.txt |
