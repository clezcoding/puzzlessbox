## Spacing Scale

Declared values (multiples of 4) — source: `brand/tokens.css` + BRAND.md:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, card accent bar |
| sm | 8px | Compact element spacing, card internal gaps |
| md | 16px | Default element spacing, column padding |
| lg | 24px | Section padding, modal body pad |
| xl | 32px | Layout gaps, masthead vertical rhythm |
| 2xl | 48px | Major section breaks (auth hero → form) |
| 3xl | 64px | Page-level spacing (auth outer) |

**Board density:** Tighter **internal** card spacing (sm/xs) than **external** column/board gaps (md). `scrollbar-gutter: stable` on board scroll containers.

**Exceptions:**
- **12px** (sketch masthead only): control gaps / compact meta rows between sm and md — not a general scale step.
- Icon-only / drag-handle touch targets ≥ **44×44px** hit area (visual icon may be 16–20px); `aria-label="Eintrag verschieben"` on handle.
- Theme toggle icon button: `aria-label="Darstellung umschalten"`.
- Mobile category tabs: min height **44px**.
- Modal max-width: **560px** content; overlay full viewport.

## Typography

| Role | Size | Weight | Line Height | Family |
|------|------|--------|-------------|--------|
| Body | 16px | 400 | 1.5 | DM Sans |
| Label | 14px | 600 | 1.4 | DM Sans |
| Heading | 20px | 600 | 1.2 | DM Sans |
| Display | 28px | 400 | 1.2 | Instrument Serif |

**Rules:**
- Exactly **2 weights** for UI: 400 + 600. Display stays 400 (serif).
- No italic headings (Hallmark). Emphasis via weight / terracotta / space.
- Mono only for timestamps, IDs, poll/debug meta — never body.
- Hierarchy via weight/color/space — not size sprawl beyond the 4 roles.
- Masthead product name: Display / Instrument Serif; board column titles: Label or Heading (DM Sans).

**Accent (`#c45c3e`) reserved for:**
1. New-item highlight pulse (~2s) and brand-soft wash (`#fce8e0`) behind pulse
2. Focus rings on brand-primary moments (login CTA secondary, welcome)
3. Active category tab indicator / Termine category accent token
4. Capture/live status dots and Apollo bandana continuity in illustrations
5. Selected checkbox accent when multi-select active

**Not accent:** default charcoal primary buttons, hairlines, body text, category pastel fills (wayfinding only).

**Category pastels** — column header tint / card accent hairline only (must not compete with terracotta):

| Category | Soft bg | Accent |

**Shape:** radius-sm **4px**, radius-md **8px**, radius-lg **10px**. Hairlines over shadows. Shadows only: card hover `0 2px 8px rgba(0,0,0,0.04)`; drag ghost may use slightly stronger elevation.

## Motion & Interaction Contract

| Concern | Spec |
|---------|------|
| Easing | UI enter: **ease-out**. Never ease-in for chrome. |
| Press | 100–160ms; `active: scale(0.97)` on buttons |
| Tooltip | 125–200ms |
| Dropdown / Sheet | 150–250ms |
| Modal | 200–300ms; center origin; enter `opacity + scale(0.95)` — **never** scale(0) |
| Cap | UI motion ≤ **300ms** |
| New-item pulse (D-08) | Terracotta / brand-soft wash ≈ **2s**, then settle — status, not celebration |
| Drag ghost (D-21) | Classic floating card (opacity ~0.95 + soft shadow); interruptible CSS/transform |
| High-frequency keys | **No** animation on arrow-reorder / typing / poll ticks |
| `prefers-reduced-motion` | Drop transform/translate; keep opacity/color/pulse via color only |
| Modal close (D-15) | X + Escape only; overlay click does **not** close; flush pending autosave first |
| Optimistic DnD (D-19) | Instant UI move; API fail → revert + toast |

## Surface Contracts

### 1. Auth — Login / Register (D-24, D-25, D-31)

- **Layout:** Brand-hero page. Top: Apollo (`apollo-splash` / `apollo-onboard` / wordmark) + Instrument Serif product name. Form below on surface card (hairline, radius-lg).
- **Tabs:** Anmelden | Registrieren — Register **always visible**; locked signup shows SIGNUP_LOCKED copy inline (do not hide tab).
- **Fields:** Email, Passwort; labels 14/600; inputs hairline border, radius-md.
- **Primary button:** Charcoal fill, label Anmelden / Konto anlegen.
- **Post-auth:** First login → short Apollo welcome (`apollo-onboard`) then Board. Later → Board. Honor `?next=` / OAuth return over welcome when present (discretion: welcome flag in `localStorage` key `pb.welcome.seen`).

### 2. Board — Desktop Kanban (D-01, D-04..D-08)

- **Focal point:** category column grid + active card stack (first read). Masthead secondary.
- Compact columns so **~5 defaults fit without H-scroll**; extra categories may H-scroll.
- Grid: hairline outer border, column rules, category pastel header wash, count in mono/muted.
- Items: only `auto_saved` + `confirmed` (never `draft`).
- Header: wordmark/title, manual refresh (`aria-label="Board aktualisieren"`), theme toggle (`aria-label="Darstellung umschalten"`), avatar menu (Logout), multi-select bulk bar when selection > 0.
- “Kategorien verwalten” panel: create + reorder; rename/color on column header (D-06).
- Live rail optional quiet status — poll-driven, not marketing hero.

### 3. Board — Mobile (D-02, D-17)

- `<768px`: single column + category **tabs/chips** (not stacked Kanban, not swipe-board).
- Category change: **long-press → Sheet** picker (shadcn Sheet). No drag-to-tab.
- Tabs scroll horizontally if many categories; active = terracotta underline/dot.

### 4. Cards (D-03, D-16, D-21..D-23)

- Collapsed: **title** + **meta line** (type · relative time) + **link thumbnail** (OG image; fallback muted bone block + link icon).
- 2px category accent hairline at top of card.
- Drag **handle only** (desktop); body click → modal.
- Checkbox multi-select + bulk move (D-22).
- Cross-category = drop on column; in-column = vertical reorder only (D-23).
- Persist `sort_order` (D-18).

### 5. Item Modal (D-09..D-15)

- Centered **Dialog** (shadcn); board dimmed; max-width 560px.
- Autosave on blur/debounce — **no** Save button; error → toast.
- Soft-delete → Undo toast ~5s (no confirm dialog) (D-12).
- Link type: full OG preview block above fields (D-13).
- Calendar 412: inline conflict UI — remote preview + **Übernehmen** / **Behalten** / **Abbrechen** (D-14).
- Type change: warning confirm + field mapping (D-10).

### 6. Settings Hub `/settings` (D-26..D-30)

| Section | Content |
|---------|---------|
| Account | Email display, password change, Logout |
| Google Calendar | 3-step wizard: Connect → Pick calendar → Verbindung abschließen; Disconnect + confirm (D-30) |
| Appearance | Theme: System / Light / Dark; optional **Klang bei neuem Eintrag** default **off** (D-36) |

OAuth starts on `app.`; callback on `api.` then return to wizard Done (Phase 1).

### 7. Live update / Offline (D-32..D-37)

- Poll ≈ **10s** while session live (not visibility-paused).
- Merge new items + remote edits/moves.
- Offline/API-down: persistent banner (VOICE offline) + **Erneut versuchen**; keep last data.
- New item: toast + pulse **always** (D-35).
- Manual refresh control in header (D-37).
- Discretion: exponential backoff on errors — 10s → 20s → 40s cap 60s + ± ±20%; reset on success.

## Rejected Patterns (do not ship)

- Purple/indigo neon, glassmorphism glow, dark-void cyberpunk, scanlines
- Pill-heavy chip clusters, multi-layer shadows, emoji as UI icons
- Cards-as-marketing tiles in first viewport of board
- Teal as brand accent
- Confirm dialog for soft-delete (Undo toast only)
- Drawer item detail or `/items/[id]` as primary (modal wins)
- Hiding Register when signup locked
