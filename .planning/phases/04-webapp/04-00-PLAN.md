<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Next.js (App Router) | Unangemeldeter Aufruf; middleware prüft Session-Cookie |
| Next.js Client → FastAPI | API-Aufrufe mit Session-Cookie (credentials: include); API validiert owner_id |
| Next.js → npm registry | shadcn + npm installs; nur offizielle shadcn-Registry |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Spoofing | login endpoint | high | mitigate | Better Auth email/password mit secure defaults; httpOnly+Secure+SameSite=Lax Cookie; keine custom Token-Logik |
| T-04-02 | Information Disclosure | session cookie | high | mitigate | httpOnly verhindert JS-Zugriff; Secure nur über HTTPS; SameSite=Lax verhindert CSRF-Default |
| T-04-03 | Tampering | JWT in cookie | medium | mitigate | API validiert JWT via JWKS (Phase 1 D-21); Client vertraut nie ungeprüften Token-State |
| T-04-05 | Tampering | npm/pnpm installs | high | mitigate | Nur offizielle shadcn-Registry; Package Legitimacy Audit aus 04-RESEARCH.md berücksichtigt (lucide-react/vitest SUS = false positive, OK); keine drittanbieter-Block-Registries |
</threat_model>
