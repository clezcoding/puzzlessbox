|----------|-------------|
| Browser (pbox) → API (api) | Credentialed CORS + JWT from Better Auth JWKS |
| GHCR image → Coolify runtime | Build-time NEXT_PUBLIC_* baked into client bundle |
| Coolify env → API process | CORS_ORIGINS and JWKS URL override code defaults |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05-01 | Spoofing | BETTER_AUTH_JWKS_URL | high | mitigate | Point JWKS at canonical pbox /api/auth/jwks; verify 200 before restart |
| T-04-05-02 | Tampering | CORS_ORIGINS | medium | mitigate | Explicit origin list — no `*` with credentials |
| T-04-05-03 | Info disclosure | NEXT_PUBLIC_* build args | low | accept | Public URLs only; no secrets in build-args |
| T-04-05-SC | Tampering | docker/build-push-action | high | mitigate | Pinned action SHAs already in deploy-web.yml |
