<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Next.js (poll) | Authenticated poll; session cookie |
| Next.js → FastAPI (poll) | GET /board-items + /categories mit session; owner_id RLS |
| Next.js → api.* (OAuth start) | Redirect zu Google consent; callback auf api.* (Phase 1) |
| api.* → app.* (OAuth return) | Redirect zurück zu wizard step 2 mit code/state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-19 | Information Disclosure | poll cross-tenant leak | high | mitigate | API filtert owner_id + RLS; poll nutzt session cookie; keine client-seitige owner_id-Übergabe |
| T-04-20 | Spoofing / CSRF | calendar OAuth callback | high | mitigate | OAuth state param (Phase 1) + Better Auth session check auf api.*; redirect nur zu app.* whitelist |
| T-04-21 | Information Disclosure | calendar list leak | medium | mitigate | GET /calendar/list owner-scoped auf api.*; wizard zeigt nur calendars des authentifizierten users |
| T-04-22 | Tampering | theme/sound localStorage | low | accept | localStorage ist client-side; kein Sicherheits-Impact; sanitize beim Lesen |
| T-04-23 | Denial of Service | poll interval flooding | low | mitigate | 10s base + backoff; keine concurrent polls; manuelle refresh debounced |
</threat_model>
