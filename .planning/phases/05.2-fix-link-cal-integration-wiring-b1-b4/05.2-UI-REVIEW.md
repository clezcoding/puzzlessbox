## Top 3 Priority Fixes

1. **Modal OG preview ≠ BoardCard thumb state machine** — Users open link modal mid-scrape / on fail and see blank muted box (no spinner, no Link2 placeholder) while card already has D-22 states — Mirror `linkThumbState` in `item-modal.tsx` og-preview: Loader2 for `pending`/`scraping`, Link2 muted placeholder when missing/broken, native `<img referrerPolicy="no-referrer">` when image present.
2. **Manual retry CTAs disabled-only, no busy affordance** — „Vorschau erneut laden“ / „Mit Google synchronisieren“ go inert with no spinner or label change during long rescrape poll (≤12s) — Add `Loader2` + `aria-busy` / „Wird geladen…“ inside Button while `rescrapePending` / `syncPending`.
3. **Calendar wizard step-2 radios + empty list** — Native `<input type="radio">` bypasses shadcn craft (D-25); empty `calendars=[]` renders blank list with no empty copy — Use shadcn `RadioGroup` (or dropdown radio items already in stack) + German empty line („Keine Kalender gefunden.“) + connecting button label „Verbinden…“.

## Detailed Findings

### Pillar 1: Copywriting (3/4)

**Pass — CONTEXT-locked CTAs present**
- `item-modal.tsx:342` — „Vorschau erneut laden“
- `item-modal.tsx:361` — „Mit Google synchronisieren“
- `item-modal.tsx:351` — „Noch nicht mit Google Kalender synchronisiert.“
- `item-modal.tsx:366` — Settings pointer copy
- `calendar-wizard.tsx:207` — „Mit Google verbinden“
- German scrape map `SCRAPE_STATUS_LABELS` (`item-modal.tsx:42-49`) — raw enum never shown (D-20); Vitest asserts same for BoardCard

**WARNING — VOICE drift on errors**
- `item-modal.tsx:186` — `toast.error("Vorschau konnte nicht neu geladen werden.")` — flat SaaS; VOICE locked error is „Da ist wohl ein Zahnrad blockiert…“
- `item-modal.tsx:208` — „Synchronisation mit Google fehlgeschlagen.“ — same pattern
- `calendar-wizard.tsx:89,103,115` — generic failure toasts

**WARNING — Collapsed / noisy status copy**
- `timed_out` and `failed` both → „Vorschau fehlgeschlagen“ (`item-modal.tsx:47-48`) — loses timeout nuance
- `ok` → „Vorschau bereit“ always shown (`item-modal.tsx:329-332`) — fights Emil silent-success (D-28); prefer show label only for non-ok / in-flight

**WARNING — Echo dialogs**
- `item-modal.tsx:476-478` — Title „Typ ändern?“ + body starts „Typ ändern?“ again
- `calendar-wizard.tsx:142-145` — „Trennen: Google-Kalender trennen?“ awkward double

**Pre-existing (flag, not phase-owned):** BoardCard non-link meta uses raw `item.type` English (`board-card.tsx:99`).

### Pillar 2: Visuals (2/4)

**Pass — BoardCard thumb craft (D-22 / D-25 / D-29–31)**
- State machine `linkThumbState` (`board-card.tsx:37-51`)
- Spinner + `sr-only` „Vorschau wird geladen“ (`board-card.tsx:136-143`)
- Muted Link2 placeholder (`board-card.tsx:145-147`)
- Native img + `referrerPolicy="no-referrer"` + `onError` → placeholder (`board-card.tsx:128-135`)
- `duration-200 ease-out` + `motion-reduce:transition-none` + `motion-safe:animate-spin`
- Icon-only controls have `aria-label` (select / move / drag)

**WARNING — Modal OG asymmetry (highest visual defect)**
- `item-modal.tsx:315-325` — aspect box renders image **or nothing**; no loading spinner, no placeholder icon when `!ogImage` / pending / broken
- Breaks visual continuity with card and CONTEXT D-22 spirit for modal (D-21: modal should be *clearer*, not emptier)

**WARNING — prefers-reduced-motion gap**
- `board-card.tsx:112` — `isNew && "animate-pulse …"` without `motion-reduce:animate-none`

**WARNING — Wizard control craft**
- `calendar-wizard.tsx:171-176` — bare native radios; no RadioGroup component under `components/ui/` (D-25 shadcn stack)

### Pillar 3: Color (3/4)

**Pass**
- Phase UI files: **0** hardcoded `#hex` / `rgb()`
- Accent/primary usage sparse: `text-primary` once on Settings link (`item-modal.tsx:365`)
- Surfaces use `bg-muted`, `text-muted-foreground`, `bg-card`, `border-border`
- New-card highlight uses brand tokens: `border-brand/60 bg-brand-soft/30` (`board-card.tsx:112`)
- Sync-miss panel: dashed border, muted text — discreet per D-23 (no card sync badge)

**WARNING**
- Live 60/30/10 on board/modal not visually verified (auth wall)
- Category `accentColor` still applied as inline `borderTopColor` (API color string) — acceptable inheritance, watch contrast on dark theme

### Pillar 4: Typography (3/4)

**Distribution in phase-touched UI files**
| Size | Files |
|------|-------|
| `text-xs` | board-card, item-modal |
| `text-sm` | board-card, item-modal, calendar-wizard |

| Weight | Files |
|--------|-------|
| `font-semibold` | board-card title, modal conflict/OG titles |
| `font-medium` | calendar-wizard headings |

Within abstract ≤4 sizes / ≤2 weights for custom classes. DialogTitle inherits shadcn default (acceptable).

**WARNING**
- Modal type control shows English enums: `Typ: {itemType}` + `ITEM_TYPES` `note|link|task|event` (`item-modal.tsx:40,439-450`) — inconsistent with German UI surface

### Pillar 5: Spacing (3/4)

**Pass**
- Dominant scale: `space-y-2`, `space-y-4`, `p-3`, `gap-2` — aligned with existing board patterns
- Justified arbitrary: `max-w-[560px]`, `aspect-[16/9]` (modal + card)

**WARNING**
- Empty modal 16:9 `bg-muted` with no content (`item-modal.tsx:315`) creates large dead vertical band when scrape pending/failed without image — spacing looks broken even when scale values are “correct”
- Wizard step 1 uses `gap-4`; steps 2–3 use `space-y-4` — minor rhythm inconsistency

### Pillar 6: Experience Design (2/4)

**Pass**
- Card: loading / placeholder / image states + `onError` fallback
- Modal: scrape retry gated to `failed|timed_out|partial`; toast **only** on manual fail (D-28); silent success path
- Modal: sync-miss panel when `!google_event_id`; Connected CTA vs Settings link (D-23, D-27)
- Conflict 412 panel preserved (Übernehmen / Behalten / Abbrechen)
- Soft-delete „Verstauen“; type-change + disconnect confirmations
- Wizard: loading text, connect `disabled={connecting}`, disconnect AlertDialog, select disabled without `selectedId`

**WARNING — Modal in-flight feedback weak**
- Rescrape polls up to 24×500ms (`item-modal.tsx:165-184`) with button only `disabled` — no spinner, OG area stays blank
- Pending/scraping scrape status shows German line but **not** thumb spinner in modal

**WARNING — Wizard empty / busy**
- Step 2: if `calendars` empty after load, only empty `<ul>` — no empty-state copy
- Connect button: disabled while connecting but label stays „Mit Google verbinden“ (no busy text)

**WARNING — Status mapping edge**
- Card: `skipped` / `partial` without image → placeholder (OK); `partial` with image → image (OK)
- Modal always shows scrape line when any status set — including `ok` (noisy)
