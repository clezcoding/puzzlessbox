## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → API /auth/google/connect | Authenticated owner starts OAuth; must carry Bearer JWT (webapp host ≠ API host) |
| Google → API /auth/google/callback | Unauthenticated browser redirect with code+state; Accept cannot be required |
| API → Webapp Settings redirect | Post-callback navigation must only target configured WEBAPP_URL origin |

| T-05.2-04-04 | Elevation | AcceptVersionMiddleware skip | medium | mitigate | Skip only /auth/google/connect and /auth/google/callback; leave vnd Accept on all other API routes |
| T-05.2-04-SC | Tampering | npm/pip installs | low | accept | No new packages in this plan |
