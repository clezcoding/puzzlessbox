<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions → GHCR | build-push uses GITHUB_TOKEN to push public API image |
| GHCR → Coolify pull | Coolify pulls public ghcr.io/clezcoding/puzzlessbox-api:latest without registry auth (D-17) |
| Workflow → Coolify webhook | curl GET to COOLIFY_API_WEBHOOK with Bearer COOLIFY_TOKEN |
| New API app → Postgres + scraper | internal Docker network; must match old app's network (Pitfall 2) |
| Public internet → api.puzzlesstool.online/health | unauthenticated liveness route (T-05-06) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-05 | Information Disclosure | deploy-api.yml webhook URL/token | high | mitigate | Only secrets.COOLIFY_API_WEBHOOK / secrets.COOLIFY_TOKEN referenced; grep gate asserts no literal URLs. |
| T-05-06 | Denial of Service | /health (public) | low | mitigate | /health is liveness-only, no DB call (api/app/routers/health.py); /ready NOT used as Traefik gate (D-12) so scraper/DB flakiness cannot black-hole API. |
| T-05-07 | Spoofing | old dockerfile app left running | medium | mitigate | D-18 immediate domain swap + stop old app dxoflgio67786lc4yilhce43; record stop timestamp in SUMMARY. |
| T-05-08 | Tampering | env var migration (15 vars) | medium | mitigate | Copy all 15 vars verbatim; update only BETTER_AUTH_JWKS_URL to pbox; verify DB connectivity after swap (Pitfall 2). |
| T-05-SC | Tampering | docker installs (python:3.14-slim base) | high | mitigate | api/Dockerfile uses pinned requirements.txt (frozen); no new packages installed in this plan. |
</threat_model>
