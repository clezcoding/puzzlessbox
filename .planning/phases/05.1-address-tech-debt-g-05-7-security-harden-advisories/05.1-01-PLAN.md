<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP -> API /internal/mcp-auth | Service-to-service bearer (X-Service-Bearer) crosses trust boundary; untrusted callers must not trigger bootstrap |
| API -> Postgres | Bootstrap writes to mcp_clients + service_principals tables; race on empty table could create duplicate / conflicting owners |
| API stdout / Coolify log stream | Plaintext token written here is visible to anyone with log access; must never contain MCP_BOOTSTRAP_TOKEN or SERVICE_BEARER_TOKEN |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05.1-01 | Information Disclosure | logger output / Coolify log stream | high | mitigate | Never call logger.* with MCP_BOOTSTRAP_TOKEN or SERVICE_BEARER_TOKEN; dev generate writes to stdout once (not logger); grep gate in Task 2 verify enforces zero matches. |
| T-05.1-02 | Tampering / Spoofing | check_and_bootstrap_first_user on concurrent calls | high | mitigate | Atomic count+insert inside a single DB transaction; second call's count>0 returns early; ponytail row-lock (SELECT ... FOR UPDATE) if needed; unique constraint on mcp_clients.id (gen_random_uuid) prevents PK collision. |
| T-05.1-03 | Spoofing | prod auto-generate path | high | mitigate | When ENV=prod and MCP_BOOTSTRAP_TOKEN empty, refuse to generate; log error without token value; return without inserting. Test asserts no row inserted and no token in log. |
</threat_model>
