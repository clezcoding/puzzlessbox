## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| MCP → API /internal/mcp-auth | Service-to-service bearer (X-Service-Bearer); untrusted callers must not trigger bootstrap | MCP bearer hash, owner_id |
| API → Postgres | Bootstrap writes to mcp_clients + service_principals; race on empty table | MCP client credentials, service principal tokens |
| API stdout / Coolify log stream | Plaintext token visible to anyone with log access | MCP_BOOTSTRAP_TOKEN, SERVICE_BEARER_TOKEN |
| Public MCP HTTP → untrusted MCP client | Anyone reaching mcp.puzzlesstool.online can GET well-known endpoint | OAuth protected-resource metadata |
| WWW-Authenticate → client fetch | Client may follow advertised resource_metadata URL | RFC 9728 metadata |
| Public internet → Traefik ingress | Untrusted clients; without HSTS, downgrade attacker can strip HTTPS | HTTPS enforcement |
| Traefik → backend containers | Banner headers leak backend framework/version info | Server, X-Powered-By headers |
| Apex domain → sibling subdomains | Apex HSTS with includeSubDomains would force HTTPS on unrelated subdomains | HSTS policy scope |

| T-05.1-01 | Information Disclosure | logger output / Coolify log stream | high | mitigate | Never call logger.* with MCP_BOOTSTRAP_TOKEN or SERVICE_BEARER_TOKEN; dev generate writes to stdout once (not logger); grep gate enforces zero matches | closed |
| T-05.1-02 | Tampering / Spoofing | check_and_bootstrap_first_user concurrent calls | high | mitigate | Atomic count+insert in single DB transaction with LOCK TABLE mcp_clients IN EXCLUSIVE MODE; second call count>0 returns early | closed |
| T-05.1-03 | Spoofing | prod auto-generate path | high | mitigate | ENV=prod + empty MCP_BOOTSTRAP_TOKEN → refuse generate; log error without token; return without inserting | closed |
| T-05.1-04 | Spoofing / SSRF | well-known authorization_servers field | high | mitigate | Omit authorization_servers from stub JSON (D-11, RFC 9728 §7.7-7.8); test asserts key absent | closed |
| T-05.1-05 | Information Disclosure | well-known resource field | medium | mitigate | resource derives from MCP_PUBLIC_BASE_URL only; never MCP_API_BASE_URL or docker hostnames | closed |
| T-05.1-06 | Spoofing | Public ingress without HSTS | high | mitigate | Traefik Headers middleware: Strict-Transport-Security max-age=31536000; includeSubDomains on leaf FQDNs (pbox, api, mcp); forceSTSHeader=true | closed |
| T-05.1-07 | Information Disclosure | Server / X-Powered-By headers | medium | mitigate | Traefik customResponseHeaders Server= and X-Powered-By= (empty strip); Next.js poweredByHeader: false | closed |
| T-05.1-08 | Tampering | Apex HSTS includeSubDomains | medium | mitigate | HSTS only on leaf FQDNs (pbox, api, mcp); NOT apex puzzlesstool.online with includeSubDomains (D-07) | closed |
