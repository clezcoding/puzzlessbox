<decisions>
## Implementation Decisions

### Local MCP bootstrap (G-05-7)
- **D-01:** Auto-bootstrap after successful first user — when `mcp_clients` is empty, create MCP client + service principal for that owner's UUID (Better Auth / first-user path, not only API `POST /auth/signup`). — **Reversibility:** costly — changes first-boot auth/ops path; undoing requires removing hooks and restoring manual env-only bootstrap
- **D-02:** Token source: prefer `MCP_BOOTSTRAP_TOKEN` from env. If env empty and `ENV=dev` (local only): generate once. **Prod: env token REQUIRED — refuse auto-generate.** Store SHA-256 hash only in DB (existing D-07 pattern). — **Reversibility:** reversible
- **D-03:** **Never log plaintext token** (OWASP Logging / MCP01; Phase 2 D-07). Dev generate may print once to stdout or write a `0600` file — not `logger.info` / Coolify log streams. — **Reversibility:** reversible
- **D-04:** Auto-set owner = first-user UUID for both `mcp_clients` and `service_principals` / `SERVICE_OWNER_ID` equivalent so MCP→API hop works without a second manual step. Guard: insert only when tables empty / count==0; use atomic count+insert. — **Reversibility:** reversible
- **D-05:** Keep lifespan `ensure_mcp_client` / `ensure_service_principal` as complementary path when env vars are already set (compose/Coolify). Auto path covers the empty-env first-signup case.

### HSTS
- **D-06:** Set `Strict-Transport-Security: max-age=31536000; includeSubDomains` on Coolify/Traefik for each public host: `pbox.puzzlesstool.online`, `api.puzzlesstool.online`, `mcp.puzzlesstool.online`. No `preload` in v1. — **Reversibility:** reversible (header change)
- **D-07:** Apply per FQDN — do **not** set apex `puzzlesstool.online` HSTS with `includeSubDomains` in this phase (avoids forcing HTTPS on unrelated subdomains). Leaf `includeSubDomains` only affects children of that leaf (usually none).

### Server / X-Powered-By banners
- **D-08:** Strip `Server` (and `X-Powered-By` if present) at Coolify/Traefik for all three public hosts. — **Reversibility:** reversible
- **D-09:** WebApp: `poweredByHeader: false` in Next.js config (official opt-out of `X-Powered-By`). — **Reversibility:** reversible

### MCP `.well-known/oauth-protected-resource` stub
- **D-10:** Serve metadata at the path WWW-Authenticate already advertises: `/.well-known/oauth-protected-resource/mcp` (matches FastMCP `TokenVerifier` + `MCP_PUBLIC_BASE_URL` / G-05-5). — **Reversibility:** reversible
- **D-11:** Minimal RFC 9728-compliant JSON only — e.g. `resource` (REQUIRED, must match resource identifier / MCP public URL), `bearer_methods_supported: ["header"]`, optional `resource_name`. **Do not** invent fake `authorization_servers` (SSRF/phishing risk per RFC 9728 §7.7–7.8). — **Reversibility:** reversible
- **D-12:** Document explicitly: static shared bearer auth remains; stub closes advertised-URL 404 — **not** full MCP Authorization Spec OAuth discovery (that would require a real AS + `authorization_servers`). Project stays on Phase 2 static bearer.

### Claude's Discretion
- Exact Coolify/Traefik middleware knobs / CLI vs UI for HSTS + header strip (prefer Coolify CLI + MCP; flag true UI-only steps per Phase 5 D-19)
- Exact stub `resource` string as long as it matches the advertised resource identifier and RFC 9728 identity rules
- Whether local compose also gets a documented `MCP_BOOTSTRAP_TOKEN` default for smoother ENV=dev (must not be a production secret)
- Test placement for bootstrap race / empty-table guards and well-known 200 response

</decisions>
