<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public internet -> Traefik ingress | Untrusted clients cross here; without HSTS, a downgrade attacker can strip HTTPS on first request |
| Traefik -> backend containers | Banner headers leak backend framework/version info to anyone curling the public URL |
| Apex domain puzzlesstool.online -> sibling subdomains | Setting apex HSTS with includeSubDomains would force HTTPS on unrelated subdomains (staging, tools, future projects), potentially breaking them |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05.1-06 | Spoofing | Public ingress without HSTS | high | mitigate | Traefik Headers middleware sets Strict-Transport-Security: max-age=31536000; includeSubDomains on each leaf FQDN (pbox, api, mcp). forceSTSHeader=true ensures it is set even on first response. No preload in v1 (D-06). |
| T-05.1-07 | Information Disclosure | Server / X-Powered-By response headers | medium | mitigate | Traefik customResponseHeaders.Server= and .X-Powered-By= (empty value strips per Pitfall 2). Next.js poweredByHeader: false disables app-layer X-Powered-By (D-09). Defense in depth: strip at proxy + disable at app. |
| T-05.1-08 | Tampering | Apex HSTS with includeSubDomains affecting sibling subdomains | medium | mitigate | Apply HSTS only on leaf FQDNs (pbox, api, mcp); do NOT set HSTS on apex puzzlesstool.online with includeSubDomains (D-07). Runbook explicitly excludes apex. Checkpoint verifies apex negative. |
</threat_model>
