### Pattern 1: Event Time Normalization
To prevent Google Calendar API `400 Bad Request` errors, event times are normalized prior to insertion or synchronization.

```python
# [VERIFIED: api/app/models/event.py:8-16]
# class Event(CoreItemMixin, table=True):
#     __tablename__ = "events"
# 
#     title: str
#     summary: str = ""
#     starts_at: datetime | None = None
#     ends_at: datetime | None = None
#     google_event_id: str | None = None
#     etag: str | None = None

# Time Normalization Pattern
if event.starts_at is None and event.ends_at is None:
    event.starts_at = datetime.now(timezone.utc)
    event.ends_at = event.starts_at + timedelta(hours=1)
elif event.starts_at is not None and event.ends_at is None:
    event.ends_at = event.starts_at + timedelta(hours=1)
elif event.starts_at is None and event.ends_at is not None:
    event.starts_at = event.ends_at - timedelta(hours=1)
```

### Anti-Patterns to Avoid
- **Orphaned Coroutines in Tests**: Mocking `asyncio.create_task` without closing the passed coroutine object, which triggers `RuntimeWarning: coroutine ... was never awaited`.
- **Hardcoding Production DSN**: Relying on a single production database connection string for all tasks instead of utilizing explicit local vs. coolify routing.

| Problem | Don't Build | Use Instead | Why |

| Mocking async tasks | Custom event loops | `unittest.mock` with `.close()` | Python's built-in mock framework supports coroutine lifecycle cleanup. |

## Common Pitfalls

### Pitfall 1: Unawaited Coroutines in Patched `create_task`
**What goes wrong:** When patching `asyncio.create_task` in tests, the coroutine passed as an argument is created but never scheduled on the event loop, causing Python to emit a `RuntimeWarning: coroutine 'schedule_autosave_poll' was never awaited`.
**Why it happens:** The mock replaces `create_task` and returns a dummy value without executing or awaiting the coroutine.
**How to avoid:** Define a side-effect function for the `create_task` mock that explicitly closes the coroutine object:
```python
def mock_create_task(coro, *args, **kwargs):
    if hasattr(coro, "close"):
        coro.close()
    return MagicMock()
```
**Warning signs:** `RuntimeWarning: coroutine ... was never awaited` in pytest output.
