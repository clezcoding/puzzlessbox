<objective>
Fix G-05-5: MCP 401 WWW-Authenticate `resource_metadata` advertises `http://localhost:8000/.well-known/oauth-protected-resource/mcp` instead of production FQDN `mcp.puzzlesstool.online`. Wire public MCP base URL (env-driven) into `TokenVerifier.base_url` so RFC 9728 metadata discovery points at the real prod host.

Purpose: Clients following OAuth protected-resource metadata must reach the prod MCP host, not a baked-in localhost default.
Output: `MCP_PUBLIC_BASE_URL` env var drives `OwnerResolvingVerifier.base_url`; Coolify MCP env sets it to `https://mcp.puzzlesstool.online`; regression test guards against localhost leak.
</objective>
