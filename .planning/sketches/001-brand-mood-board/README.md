# Sketch 001: Brand Mood Board

## Design Question
Wirkt warm-first + adult-playful auf dem echten Kategorien-Board (nicht nur auf Swatches)?

## How to View
```bash
open .planning/sketches/001-brand-mood-board/index.html
```

## Variants
- **A: Honey Mist** — Pfirsich-Wash, Coral-Honey Primary, Teal-Akzent; weich & einladend
- **B: Sage Play** — Salbei-Grün-Wash, Coral Primary; frischer, outdoor-warm
- **C: Ocean Honey** — Slate-Blau-Wash, Amber Primary; klarer, etwas tooliger

## What to Look For
- Fühlt sich die Marke einladend an, ohne kindisch zu wirken?
- Bleibt Clean als Struktur lesbar (Spalten, Cards, Typo)?
- Welcher Wash/Akzent passt zu „Capture-Box“ ohne AI-Slop?
