# Sketch 001: Brand Mood Board (v2)

## Design Question
Nach Feedback „v1 zu warm/bunt/verspielt“: Wirkt **restrained / adult** auf dem Board?

## How to View
```bash
open .planning/sketches/001-brand-mood-board/index.html
```

## Variants (v2)
- **A: Quiet Stone** — Steingrau, Charcoal-CTA, Teal nur auf Status
- **B: Cool Mist** — kühles Slate, ein stiller Teal-Akzent
- **C: Soft Ember** — fast mono; Wärme nur auf dem Primary-Button

## Rejected (v1)
Honey Mist / Sage Play / Ocean Honey — zu warm, zu farbig, zu verspielt (Blob, bunte Spalten).

## What to Look For
- Genug Charakter ohne Kind-/Kirmes-Feeling?
- Soft Ember: ist *eine* warme CTA genug „warm-first“-Rest?
- Oder eher komplett cool (A/B)?
