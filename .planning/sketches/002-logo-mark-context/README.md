# Sketch 002: Logo Mark Context

## Design Question
Welche Marke liest sich als Puzzlessbox — Lettermark, Box-Hint oder abstrakte Form — im Header, Favicon und Social-Preview?

## How to View
```bash
open .planning/sketches/002-logo-mark-context/index.html
```

## Variants
- **A: Lettermark P** — Rounded square + soft box-notch; Wortmarke Syne
- **B: Open Tray** — Offene Box/Tray-Silhouette (Metapher stärker, kein Maskottchen)
- **C: Puzzle Notch** — Geometrische Marke mit Puzzle-Einschnitt

## What to Look For
- Lesbar bei 16×16 (Favicon) und 40×40 (Header)?
- Subtile Metapher oder zu literal/kindisch?
- Passt zur Honey-Mist-Richtung aus Sketch 001?
